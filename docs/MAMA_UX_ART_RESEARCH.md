# MAMA'S COMING! — UX/UI และทิศทางภาพจาก research

วันที่ศึกษา: 23 ตุลาคม 2026 · ขอบเขต: เกม MamasKitchen ไม่ใช่แคมเปญ DreamRush

สถานะ: ข้อเสนอจากการอ่านงานวิจัย บทความผู้พัฒนา และบทสรุปเซสชัน GDC เทียบกับภาพในเกมจริง ยังไม่ใช่การรับรองว่าภาพเป้าหมายถูกนำเข้าเกมแล้ว ไม่ได้ดูวิดีโอ GDC ทั้งเซสชัน และไม่ได้ทำ blind playtest ในรอบนี้

## ข้อสรุปสำหรับเกมนี้

เป้าหมายของ UX คือให้ผู้เล่นเข้าใจว่าปัญหาคืออะไร อะไรทำอะไรได้ และการกระทำสำเร็จหรือยัง โดยยังเป็นคนเลือกเส้นทางและวิธีเอง ความยากที่ควรเก็บไว้คือการจัดลำดับงานภายใต้เวลาและผลข้างเคียงของการแก้ปัญหา ความยากจากการเดาปุ่ม เดาพิกัดวางของ และอ่านข้อความที่แย่งกันขึ้นควรลดลง

รอบแก้ก่อนหน้าช่วยเรื่องปุ่ม คำใบ้และสถานะ แต่ยังเป็นการเพิ่มความอ่านง่ายบนฉากเดิม ไม่ใช่ art pass เต็มรูปแบบ จุดที่ยังทำให้ภาพดูเป็น prototype คือรูปทรงแข็ง วัสดุแยกชนิดไม่ชัด แสงค่อนข้างทั่วถึง สีและลายของฉากแย่งความเด่นกับของใช้งาน และตัวละครลายเส้นเข้มอยู่ในโลกที่ใช้ภาษาภาพอีกแบบ

## UX ที่แนะนำต่อจากเวอร์ชันปัจจุบัน

### ช่วงเริ่ม

- ภาพเปิดสั้น: เด็กตื่น เสียงน้ำกับควันบอกสถานการณ์ ข้อความแม่กลับในห้านาทีบอกเดิมพัน
- ให้เดินสำรวจและหยิบของได้เอง อย่าบังคับลำดับภารกิจ
- สอนปุ่มเฉพาะตอนมีสิ่งที่ใช้ปุ่มนั้นได้จริง การใช้เครื่องมือควรมีตัวอย่างภาพเคลื่อนไหวสั้นที่เรียกดูซ้ำได้
- พิจารณาช่วงทดลองครั้งแรก/โหมดซ้อมเป็นทางเลือก ต้องทดสอบก่อนเปลี่ยนสมดุลเวลา ไม่เปลี่ยนเงียบ ๆ จากผล research นี้

### ของรกและหมี

จุดเก็บต้องมีเหตุผลที่เห็นในฉาก เช่น หมอนกับของเล่นร่วมชุดช่วยสื่อว่าเป็นเตียงของเด็ก ขั้นต่อไปที่ควรทดลองคือ **พื้นที่เก็บที่ยอมรับได้** แทนพิกัดกับองศาเดียว: ถ้าวางหมีบนบริเวณเตียงหรือชั้นของเล่นที่กำหนด ควรนับว่าเก็บเรียบร้อย เงาจุดเดิมเป็นการช่วย ไม่ใช่สิ่งที่ผู้เล่นจำเป็นต้องเชื่อฟัง

นี่เป็นข้อเสนอเปลี่ยนกติกาที่ยังไม่ได้ implement ปัจจุบัน MessyProp ยังเทียบ homePosition/homeRotation และ tolerance จึงต้องออกแบบการชน ตำแหน่งที่นั่ง และการตรวจของแม่ร่วมกันก่อนขยายพื้นที่

### ไฟ

ให้เห็นเหตุและผลของแต่ละการกระทำ: หม้อมีคราบ/ควัน เตามีสถานะเปิด ฝาหม้อมีทรงที่จับคู่กับหม้อได้ ถังดับเพลิงมีสายฉีดและตำแหน่งแขวนที่หาเจอ

คำใบ้เป็นชั้น: (1) วัสดุ เสียง และตำแหน่งในฉาก (2) คำอธิบายหน้าที่เมื่อมอง/ถือ (3) คำใบ้เพิ่มที่ผู้เล่นเรียกเอง สถานะต้องแยก **ปิดเตา / ดับไฟ / ระบายควัน / เก็บหลักฐาน** อย่างชัดเจน ไม่เหมารวมว่าทำอย่างเดียวจบ

### HUD

- คงบนจอ: เวลาที่แม่จะถึง เป้าหมายสั้น และปุ่มที่ใช้กับเป้าหมายปัจจุบัน
- ข้อมูลของในมือเป็นแถบสั้น ขยายรายละเอียดเมื่อขอหรือพบเครื่องมือครั้งแรก
- งานทั้งหมดกับภาพรวมรายห้องอยู่ใน Tab สถานะที่สำเร็จควรมีประวัติสั้นให้ทบทวน
- เหตุฉุกเฉินแจ้งสั้นแล้วลดระดับ ไม่ทิ้ง banner ใหญ่ค้างขณะที่ผู้เล่นต้องมองหม้อ
- คำพูดตัวละคร เสียงโทรศัพท์ และผลสำเร็จต้องมีลำดับความสำคัญ ไม่ขึ้นทับพร้อมกันหลายกล่อง
- คำใบ้เพิ่มเติมควรมีทั้งกดค้างและสลับเปิด/ปิดให้เลือก ต้องมี label ที่ตรงกับอุปกรณ์ที่ใช้
- ตรวจตัวอักษรไทยและ safe area ที่ 720p/1080p/1440p และมุมกล้องจริงก่อนรับรอง

## ทิศทางภาพที่แนะนำ: บ้านจิ๋วงานประดิษฐ์ในละครตลกครอบครัว

รักษาเด็กแอปเปิลกับบุคลิกตลกของเกม แต่ทำให้ทั้งบ้านใช้ภาษาภาพเดียวกัน เป็น 3D ที่มีความประณีตของรูปทรงและวัสดุ ไม่เน้นความสมจริงแบบภาพถ่าย

| ส่วน | ข้อสังเกตจากภาพปัจจุบัน | เป้าหมายที่เสนอ |
|---|---|---|
| รูปทรง | ขอบกล่องแข็งและของบางชิ้นเล็ก/แบนจนอ่านชนิดยาก | เฟอร์นิเจอร์ขอบมน มีความหนา ขา รอยต่อและสัดส่วนที่ออกแบบ เครื่องมือมีด้ามจับเด่น |
| สี | พื้นเหลือง ลายผนังส้ม ตู้เขียว และของชมพูเด่นพร้อมกัน | ผนังครีม ตู้เขียว sage หม่น ไม้อุ่น; สีอิ่มสงวนให้เด็ก ของใช้งาน และอันตราย ไม่ใช้สีอย่างเดียวบอกความหมาย |
| วัสดุ | หลายพื้นผิวดูเป็นสีทาทับแบบเดียวกัน | ผ้าด้านและมีรอยพับ ไม้มีลายหยาบน้อย เซรามิกมีเงานุ่ม โลหะมี highlight คุมได้ แยกผิวเปียกจากผิวแห้ง |
| แสง | ความสว่างทั่วถึง เงาสัมผัสบาง ทำให้ของไม่หนักแน่น | แสงหน้าต่างอุ่นเป็นทิศหลัก เงาเย็นนุ่ม เงาสัมผัสใต้ของ ฉากยังอ่านได้เมื่อควันขึ้น |
| ตัวละคร | เส้นขอบและเส้นรายละเอียดหนากว่าโลก | ลดรายละเอียดเส้นภายใน ใช้เส้นขอบที่คุมความหนาหรือ rim light และ shading ที่สอดคล้องกับฉาก |
| น้ำ/ไฟ | เอฟเฟกต์บางส่วนอ่านได้จากมาตรวัดมากกว่าพื้นผิว | น้ำมีขอบแอ่งและเงาสะท้อนเฉพาะส่วน ไฟมี silhouette กับจังหวะชัด ควันไม่กลบของที่กำลังใช้ |
| กล้อง | มุมสูงทำให้ของบนเคาน์เตอร์แบน | ทดลองมุมที่ยังอ่านทางเดินได้แต่เห็นหน้าของเครื่องมือ ใช้ collision/cutaway ที่ไม่กะพริบ ไม่ล็อกมุมตามภาพสวยเพียงภาพเดียว |
| UI | กรอบกระดาษหลายใบกินพื้นที่และเด่นเท่ากัน | ใช้ความเป็นกระดาษกับองค์ประกอบหลักเพียงบางจุด ที่เหลือเป็นข้อความและไอคอนเรียบ ลำดับสายตาอ่านได้ |

Palette เริ่มต้นสำหรับทดลอง: cream `#F3E8D6`, sage `#879C84`, warm wood `#B9855C`, ink `#28343A`, interaction teal `#3C9B94`, emergency coral `#D85A48`. นี่เป็นตัวเลือก art direction ของเรา ไม่ใช่ค่าที่งานวิจัยกำหนด

## ลำดับทำงานที่ลดความเสี่ยง

1. ทำ kitchen art pilot ในฉากสำเนา เก็บ layout และ collider เดิม เปรียบเทียบกล้องเดียวกัน เวลาเดียวกัน สถานะควันเดียวกัน
2. ทำตู้ เคาน์เตอร์ เตา หม้อ ฝา และถังดับเพลิงเป็นชุดมาตรฐานก่อนเพิ่มของตกแต่ง
3. ตั้งวัสดุ แสง และภาษาภาพตัวละครให้เข้าชุด แล้วตรวจจากระยะเล่นจริง
4. ทดลอง HUD ที่ลดกรอบลง พร้อมคำใบ้ในฉากและ interaction feedback
5. ทดสอบผู้เล่นใหม่ก่อนขยายไปทั้งบ้าน อย่า rebuild ทั้งบ้านจาก generator เดิม เพราะเสี่ยงทับงานฉากที่มีอยู่

ภาพ concept ที่สร้างประกอบเป็นภาพเป้าหมาย ไม่ใช่หลักฐานว่าทำได้ใน Unity แล้ว ต้องแปลงเป็นโมเดล วัสดุ แสง และ UI จริง และวัดประสิทธิภาพอีกครั้ง

## เกณฑ์ทดลองที่เสนอ (ยังไม่ใช่ผลทดสอบ)

- ผู้เล่นใหม่อธิบายเป้าหมายได้หลังเริ่ม 30 วินาที โดยไม่มีคนข้าง ๆ บอก
- หยิบหมีแล้วหาพื้นที่เก็บที่สมเหตุผลได้ในประมาณ 20 วินาที; กดวางแล้วไม่สงสัยว่าทำสำเร็จหรือยัง
- ถึงครัวแล้วระบุได้ว่ามีปัญหาอะไร และค้นพบทางแก้ไฟอย่างน้อยหนึ่งวิธีด้วยฉาก/feedback
- ผู้เล่นสามารถเลือกทำงานคนละลำดับและใช้คนละวิธี โดยยังเข้าใจกติกา
- ภาพขาวดำและภาพย่อยังแยกเด็ก เครื่องมือ และอันตรายออกจากพื้นหลังได้
- ทุกอย่างที่ผู้เล่นถืออ่านชนิดได้จากกล้องจริง ไม่ต้องซูมถึงจะรู้ว่าเป็นอะไร
- เก็บเวลาไปสู่การกระทำที่มีความหมายครั้งแรก จำนวนการกดผิดเป้าหมาย การขอคำใบ้ และเหตุผลที่วางของผิด เริ่มด้วย 5 คนเพื่อหาอาการซ้ำ ไม่อ้างว่าเพียงพอพิสูจน์ผลทางสถิติ

## ภาพเป้าหมาย

ใช้ภาพ `DevBridge/mama-ux/fire-options.png` เป็น reference ของ layout/ตัวละคร และบันทึก prompt เต็มไว้ใน `docs/MAMA_ART_TARGET_PROMPT.txt`.

สร้างด้วย built-in image_gen และเก็บไว้ที่ [ภาพเป้าหมายครัว v1](art-targets/mama-kitchen-art-target-v1.png). ภาพนี้ใช้ตู้ sage ผนังครีม ขอบเฟอร์นิเจอร์มน วัสดุแยกชนิด แสงหน้าต่างและเงาสัมผัส พร้อม HUD สั้น ได้ตรวจรูปทรงตัวละคร การจัดพื้นที่ครัว ข้อความไทย และพื้นที่มองเห็นการเล่นแล้ว

ข้อจำกัดของภาพ: รายละเอียดของพร็อพ/หน้าต่างบางจุดเป็นการตีความใหม่ มีเงาฟุ้งที่ขอบภาพและพื้นสะท้อนค่อนข้างมาก เมื่อนำหลักการไปทำในเกมต้องคุมความคมชัดตลอดพื้นที่เล่น ลดการสะท้อนบนพื้นแห้ง และรักษาเส้นทาง/ระยะ interaction เดิม การเห็นภาพสวยหนึ่งภาพไม่ยืนยันประสิทธิภาพหรือความอ่านง่ายขณะกล้องเคลื่อนที่

ผลลัพธ์นี้เป็น visual proposal ไม่มีการใช้ภาพแทนฉากหรือ collider และไม่มีการเปลี่ยนโค้ดเกมในรอบ research นี้
