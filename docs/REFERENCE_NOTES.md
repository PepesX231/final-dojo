## Art Review เบื้องต้นของโมเดลแอปเปิ้ล (v3)
**ผ่าน:** silhouette แอปเปิ้ลชัด (ไม่ใช่ทรงกลมเป๊ะ), ก้านเอียง + ใบเล็กไม่บังหน้า, ผิวไม่เงาเปียก, ไม่มีรอยกัด/โลโก้, สีตรง Apple Red/Cream
**ต้องแก้ก่อนเข้าเกม (REVISE):**
1. Scale: สูงรวม ~3.5u → ต้องเป็น 1.2u, origin ที่เท้า
2. มือประสานเป็นชิ้นรวม → แยกมือซ้าย/ขวาเพื่อแกว่งแขนตอนวิ่ง (ท่ามือประสานใช้เป็น idle — เก็บบุคลิก "cheeky")
3. Curves (แขน/ขา/ปาก/เปลือกตา) → convert เป็น mesh + ลด poly สำหรับเกม (body 6,240 verts โอเค)
4. Material procedural → bake/สร้างใหม่เป็น URP material (Apple Skin preset)
5. **ขัด GDD §4.2**: GDD ระบุชุดนอน (pajama top/pants/slippers) แต่โมเดลไม่มี — และสีหน้าเริ่มต้น "กวน" ต่างจาก "curious/playful" → ต้องให้ผู้ใช้ตัดสิน (เสนอ: คงหน้ากวนเป็นเอกลักษณ์ + เพิ่มหมวกนอน/ผ้าพันคอเล็ก ๆ แทนชุดนอนเต็มตัว เพื่อไม่บัง silhouette)
